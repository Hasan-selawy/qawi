FEATURE — Workout History for both Coach and Member.

BACKEND:
Add these endpoints if they don't exist:

GET /api/v1/workouts/member/{memberId}/history
Returns all completed workout days with logged exercises:
[
  {
    "dayId": "...",
    "dayName": "Monday - Chest Day",
    "dayNameAr": "الاثنين - يوم الصدر",
    "date": "2026-05-02",
    "completedAt": "2026-05-02T18:30:00",
    "exercises": [
      {
        "exerciseName": "Bench Press",
        "exerciseNameAr": "بنش برس",
        "targetSets": 4,
        "targetReps": 10,
        "actualSets": 4,
        "actualReps": 10,
        "actualWeight": 65.0,
        "loggedAt": "2026-05-02T18:35:00"
      }
    ]
  }
]

GET /api/v1/workouts/exercise/{exerciseTemplateId}/history/{memberId}
Returns history for ONE specific exercise for a member:
[
  {
    "date": "2026-05-02",
    "actualWeight": 65.0,
    "actualSets": 4,
    "actualReps": 10
  },
  {
    "date": "2026-04-28",
    "actualWeight": 60.0,
    "actualSets": 4,
    "actualReps": 10
  }
]
This shows progression over time for one exercise.

WEB DASHBOARD (Coach):

1. MEMBER DETAIL → PLAN TAB:
When coach clicks a completed day (✅):
Show a modal with:
- Day name + date
- List of exercises with:
  Exercise name | Target: 4×10 | Actual: 4×10 @ 65kg
  Green if hit target, orange if below target
- "Personal Best" badge if weight is highest ever

2. New tab in Member Detail: "HISTORY"
- Timeline of all completed workout days (newest first)
- Each row: date, day name, exercises count, 
  completion status
- Click any row → expand to see all exercises + weights
- Filter by: This Week | This Month | All Time
- At top: Personal Records section showing
  highest weight ever lifted per exercise

3. EXERCISE HISTORY MODAL:
When coach clicks any exercise name (anywhere in the app):
Show a small chart/list:
"Bench Press — Sam's History"
Date        | Weight | Sets | Reps
2026-05-02  | 65kg   | 4    | 10  ↑
2026-04-28  | 60kg   | 4    | 10  ↑
2026-04-21  | 55kg   | 4    | 10
Shows progression with up arrow if weight increased.
