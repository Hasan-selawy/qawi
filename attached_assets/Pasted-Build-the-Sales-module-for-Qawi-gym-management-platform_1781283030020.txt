Build the Sales module for Qawi (قوي) gym management platform.

CONTEXT

Read CLAUDE.md for full project context.
Stack: Java 17 + Spring Boot 3, PostgreSQL, JWT auth, React 18 + TypeScript + Tailwind
Theme: Background #0A0F1E, Accent #22C55E, dark throughout
All endpoints must enforce gym isolation and role-based access control.


THERE ARE 2 SEPARATE SALES CONCEPTS

LEVEL 1 — SUPER ADMIN SALES PIPELINE

Hasan's team tracking gyms to sell Qawi to.
Only visible to SUPER_ADMIN role.

LEVEL 2 — GYM-LEVEL MEMBER LEADS

Each gym tracking potential members (walk-ins who didn't sign up yet).
Visible to GYM_ADMIN and RECEPTIONIST roles within their gym only.


LEVEL 1 — SUPER ADMIN GYM PIPELINE

New entity: GymLead

id (UUID)
gymName (String)
contactName (String)
phoneNumber (String)
city (String)
source (Enum: WEBSITE_FORM, WHATSAPP, MANUAL_VISIT, REFERRAL)
status (Enum: NEW, CONTACTED, DEMO_SCHEDULED, TRIAL_STARTED, CONVERTED, LOST)
potentialPlanId (String, nullable) — which Qawi plan they might take
notes (String, nullable)
nextFollowUpDate (LocalDate, nullable)
lastContactedAt (LocalDateTime, nullable)
createdAt (LocalDateTime)
assignedTo (String, nullable) — sales person name

New endpoints (SUPER_ADMIN only):

GET    /api/v1/super/leads               — all gym leads, filterable by status/city
POST   /api/v1/super/leads               — create new gym lead manually
PUT    /api/v1/super/leads/{id}/status   — update status + add note + set next follow-up
POST   /api/v1/super/leads/{id}/note     — add a note to lead history
GET    /api/v1/super/leads/pipeline      — pipeline summary: count + potential JOD per stage
GET    /api/v1/super/leads/followups     — leads with follow-up due today or overdue

Note: ContactRequest (existing entity) feeds into this — when a gym submits the contact
form it auto-creates a GymLead with status=NEW.

LEVEL 2 — GYM-LEVEL MEMBER LEADS

New entity: MemberLead (gym-scoped)

id (UUID)
gymId (UUID, FK → Gym) — strict gym isolation
name (String)
phoneNumber (String) — required
notes (String, nullable)
status (Enum: NEW, CONTACTED, VISIT_SCHEDULED, SIGNED_UP, LOST)
createdBy (UUID, FK → User) — who added this lead
createdAt (LocalDateTime)
lastUpdatedAt (LocalDateTime)

New endpoints (GYM_ADMIN + RECEPTIONIST, gym-scoped):

GET    /api/v1/gym/leads                 — all member leads for this gym
POST   /api/v1/gym/leads                 — add new member lead
PUT    /api/v1/gym/leads/{id}            — update status + notes
DELETE /api/v1/gym/leads/{id}            — delete lead
POST   /api/v1/gym/leads/{id}/convert    — convert lead to full member
        Request: { email, coachId, subscriptionEndDate, planId }
        Action: creates User with MEMBER role, removes from leads
