═══════════════════════════════
NEW NUTRITION CONCEPT
═══════════════════════════════

COACH'S JOB (simple):
  Set daily targets for each member:
  - Target calories (e.g. 2,200 kcal)
  - Target protein (e.g. 180g)
  - Target carbs (e.g. 220g)
  - Target fat (e.g. 70g)
  - Water target (e.g. 2.5L)
  - Goal: (Weight Loss / Muscle Gain / Maintenance)
  
  Coach sets these ONCE and updates as needed.
  Coach can see how close member is hitting targets.

MEMBER'S JOB (daily):
  Log everything they eat throughout the day.
  AI calculates all macros automatically.
  Member sees progress toward daily targets.

NEW API ENDPOINTS:

NUTRITION TARGETS (Coach):
POST /api/v1/nutrition/targets
  Request: { memberId, targetCalories, targetProtein,
             targetCarbs, targetFat, targetWater, goal }

GET  /api/v1/nutrition/targets/{memberId}
  Returns member's current nutrition targets

PUT  /api/v1/nutrition/targets/{memberId}
  Update targets

FOOD LOGGING (Member):
POST /api/v1/nutrition/log
  Request: { foodName, quantity, unit, mealType }
  
  BACKEND LOGIC:
  1. Take foodName + quantity + unit
  2. Call OpenAI API with this prompt:
     "Calculate the nutritional content for:
     [quantity] [unit] of [foodName].
     This is for a Middle Eastern / Arabic diet.
     Return ONLY a JSON object:
     {
       foodName: string (English),
       foodNameAr: string (Arabic),
       calories: number,
       protein: number (grams),
       carbs: number (grams),
       fat: number (grams),
       fiber: number (grams),
       sugar: number (grams),
       confidence: number (0-1),
       notes: string (any important notes)
     }
     Be accurate for these common Arabic/Middle Eastern foods:
     shawarma, mansaf, falafel, hummus, knafeh, 
     musakhan, maqluba, fattoush, tabbouleh, 
     ka'ak, maamoul, etc."
  
  3. Parse OpenAI response
  4. Save FoodEntry to database
  5. Return full entry with calculated macros
  
  Response: {
    entry: FoodEntry,
    dailySummary: { 
      calories: { consumed, target, remaining },
      protein: { consumed, target, remaining },
      carbs: { consumed, target, remaining },
      fat: { consumed, target, remaining }
    }
  }

GET  /api/v1/nutrition/log/today/{memberId}
  Returns today's food entries grouped by meal type
  + daily totals vs targets
  + progress percentages

GET  /api/v1/nutrition/log/history/{memberId}
  Query: ?days=7 or ?from=date&to=date
  Returns daily summaries for date range:
  [{date, totalCalories, totalProtein, totalCarbs, 
    totalFat, targetCalories, goalAchieved}]

DELETE /api/v1/nutrition/log/{entryId}
  Member can delete a food entry

PUT    /api/v1/nutrition/log/{entryId}
  Member can edit quantity → AI recalculates

POST /api/v1/nutrition/water
  Log water intake
  Request: { amount } (in liters)

GET  /api/v1/nutrition/water/today/{memberId}
  Returns today's water total + target

FOOD SEARCH (for suggestions):
GET  /api/v1/nutrition/search?q=shawarma
  Search our Arabic food database first
  If not found → use OpenAI to calculate
  Returns: list of food items with macros

COACH OVERVIEW:
GET  /api/v1/nutrition/coach/overview/{memberId}
  Returns:
  - Member's targets
  - Today's progress
  - Last 7 days adherence (% of days hitting targets)
  - Average calories last 7 days
  - Trend (improving/declining/stable)

AI ACCURACY NOTES FOR OPENAI
═══════════════════════════════

Include these in your OpenAI system prompt:

Common Arabic/Middle Eastern foods to know:
- شاورما دجاج (Chicken Shawarma): ~450 kcal per 300g
- منسف (Mansaf, lamb + rice): ~800 kcal per serving
- فلافل (Falafel): ~57 kcal per piece
- حمص (Hummus): ~166 kcal per 100g
- كنافة (Knafeh): ~400 kcal per 100g
- مسخن (Musakhan): ~650 kcal per serving
- مقلوبة (Maqluba): ~550 kcal per serving
- تبولة (Tabbouleh): ~100 kcal per 100g
- فتوش (Fattoush): ~90 kcal per 100g

Common Jordanian meal sizes:
- Rice serving in Jordan: typically 200-300g cooked
- Bread (khubz): 1 piece = ~150g = ~370 kcal
- Olive oil: very common, don't underestimate

Always ask for clarification in notes field if:
- The food could vary significantly in preparation
- The quantity seems unusual
- Confidence < 0.7
