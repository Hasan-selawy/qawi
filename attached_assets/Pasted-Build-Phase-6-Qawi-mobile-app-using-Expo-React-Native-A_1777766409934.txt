Build Phase 6 — Qawi mobile app using Expo + React Native.
App name: "Qawi - قوي"

TECH STACK:
- Expo SDK 51
- React Native
- TypeScript
- Expo Router (file-based routing)
- Axios
- React Query (TanStack Query)
- AsyncStorage (for token storage)
- i18n-js + expo-localization (Arabic/English)
- Expo Notifications
- Expo Image Picker (progress photos)
- React Native Reanimated (animations)
- React Native Safe Area Context
- @expo/vector-icons

DESIGN SYSTEM:
- Background: #0A0F1E
- Surface: #111827
- Card: #1E293B
- Accent: #22C55E (green)
- Danger: #EF4444
- Warning: #F59E0B
- Text Primary: #F8FAFC
- Text Secondary: #94A3B8
- Border: #1F2937
- Font: Cairo (Arabic), Inter (English)
- Border radius: 16px on cards
- All screens dark theme

API:
- Base URL stored in .env as EXPO_PUBLIC_API_URL
- Same backend at port 9000
- Auth: Bearer token in every request header
- Token stored in AsyncStorage

═══════════════════════════════════
MEMBER SCREENS
═══════════════════════════════════

MEMBER TAB BAR (5 tabs):
🏠 Home | 💪 Workout | 📍 Check-in | 🥗 Nutrition | 📊 Progress

TAB 1 — HOME (🏠):
- Header: "مرحباً [Name] 👋" or "Welcome [Name] 👋"
- Subscription alert banner if expiring soon (orange)
- TODAY'S WORKOUT CARD:
  - Plan name + day name
  - Exercise count
  - "Start Workout" button → workout screen
  - If rest day → "Rest Day 😴"
  - If no plan → "No plan assigned yet — ask your coach"
- STREAK CARD: 🔥 X day streak
- QUICK STATS: total workouts completed, current plan days
- RECENT NOTIFICATIONS: last 2 previews with bell icon

TAB 2 — TODAY'S WORKOUT (💪):
- Day name + date at top
- Exercise list — each card shows:
  - Arabic name (large) + English name (small)
  - Coach note if exists: 📌 "Use machine #1" (yellow info box)
  - Target sets × reps
  - Weight input (empty, placeholder "Enter weight used (kg)")
  - Sets completed toggle per set
  - YouTube video button (red play icon → opens link)
- "Complete Workout" button at bottom:
  → POST /api/v1/workouts/logs for each exercise
  → PUT /api/v1/workouts/days/{dayId}/complete
  → Green checkmark success animation + confetti
  → Updates streak

TAB 3 — CHECK-IN (📍):
- Large green "Check In" button centered
- POST /api/v1/attendance/checkin
- On success: streak bounce animation 🔥
- "🔥 X day streak!"
- Last 10 checkins calendar heatmap
- If already checked in today → "Already checked in today ✅"

TAB 4 — NUTRITION (🥗):
- Meal cards by type:
  🌅 Breakfast | ☀️ Lunch | 🌙 Dinner | 🍎 Snack
- Each card: description (AR or EN), calories, protein
- If no plan → "No nutrition plan assigned yet"

TAB 5 — PROGRESS (📊):
- MEASUREMENTS section:
  Grid: Weight, Height, Chest, Waist, Arms, Legs, Body Fat
  Each shows value + delta from previous
  "Add Measurement" button → form modal
- PROGRESS PHOTOS:
  Horizontal scroll with dates
  "Add Photo" button → image picker
- BODY CHART: weight over time line chart

PROFILE SCREEN (accessible from home):
- Avatar (gradient + initials)
- Name, email, gym name
- Subscription end date + status badge
- Language toggle AR | EN
- Notifications toggle
- Logout button (red)

COACH TAB BAR (5 tabs):
👥 Members | 💪 Plans | 📋 Notes | 📚 Library | 👤 Profile

TAB 1 — MEMBERS (👥):
- Search bar at top
- Filter tabs: All | Active | Inactive | Expiring

MEMBER DETAIL PAGE (coach):
Full screen with 5 tabs:

  Tab 1 — TODAY:
  - Today's workout day for this member
  - Each exercise with sets/reps
  - Whether member completed it (✅ if done)
  - Actual weights the member logged
  - Coach note field per exercise (editable inline)

  Tab 2 — PLAN:
  - Current plan name + date range
  - Full calendar grid of all days
  - Color coded: ✅ completed | 😴 rest | ⏳ pending | 🔵 today
  - Tap day → see exercises list
  - "Create New Plan" button → plan builder wizard

  Tab 3 — NUTRITION:
  - Member's meal plan
  - Meal cards (Breakfast, Lunch, Dinner, Snack)
  - "Create Nutrition Plan" button → form

  Tab 4 — MEASUREMENTS:
  - Latest body stats grid
  - Weight trend chart
  - "Add Measurement" button → form

  Tab 5 — NOTES:
  - Notes timeline (newest first)
  - Add note textarea at top
  - Edit/delete notes

TAB 2 — PLANS (💪):
- List of workout plans coach created
- Each: member name, plan name, date range, days count
- "Create New Plan" button → 3 step wizard:
  Step 1: Select member + plan name + date range
  Step 2: Calendar grid — tap any date to add day,
          toggle rest day, day name EN + AR
  Step 3: For each day → category grid → exercise list
          → tap to add → set sets/reps/note inline
- Save → success animation

TAB 3 — NOTES (📋):
- Member selector dropdown
- Note textarea with character count
- Save button
- Notes timeline (newest first)
- Edit/delete per note
- Calls GET/POST/PUT/DELETE /api/v1/notes

TAB 4 — LIBRARY (📚):
- Category filter tabs with emoji icons:
  💪 Chest | 🏋️ Back | 🦵 Legs | 🎯 Shoulders | 💪 Arms | 🔥 Core | 🏃 Cardio
- Search bar
- Exercise cards:
  - Name (AR or EN based on language)
  - Sets × reps defaults
  - YouTube button (red play icon)
- "Add Custom Exercise" button → modal

TAB 5 — PROFILE (👤):
- Avatar + name + email
- Language toggle AR | EN
- Logout button (red)
