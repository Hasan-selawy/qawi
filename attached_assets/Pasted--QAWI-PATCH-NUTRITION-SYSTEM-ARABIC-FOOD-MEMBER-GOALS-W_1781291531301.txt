شاورما لحمة

should return:

Chicken Shawarma

Beef Shawarma

q=حمص

should return:

Hummus / حمص

Search should check:

* foodName
* foodNameAr
* searchKeywords

Add Arabic normalization:

* ignore diacritics
* normalize أ إ آ to ا
* normalize ة to ه or support both
* normalize ى to ي
* trim spaces

Search should use local ArabicFoodCache only.

AI should only be used when user presses Calculate or Add and no strong local match exists.

# Plan Logic

A member can have one active nutrition calendar plan at a time.

Today’s target should be resolved in this order:

1. If there is an active NutritionCalendarPlan with a NutritionPlanDay for today, use that day target.
2. Else use active NutritionTarget default target.
3. Else return null target.

Today’s suggestions should be resolved in this order:

1. Suggestions linked to today’s NutritionPlanDay.
2. Suggestions with suggestionDate = today.
3. General suggestions for member with no date if needed.
4. Else empty list.

## POST /api/v1/nutrition/plans

Create nutrition calendar plan.

Request:

memberId

title

startDate

endDate

defaultTargetCalories

defaultTargetProtein

defaultTargetCarbs

defaultTargetFat

defaultTargetWater

goal

notes optional

Behavior:

* create NutritionCalendarPlan
* auto-create NutritionPlanDay for every day between startDate and endDate
* fill each day with default targets
* set isActive = true
* deactivate old active plans for same member if needed

---

## GET /api/v1/nutrition/plans/member/{memberId}

Return active and previous nutrition calendar plans for member.

Allowed:

* member self
* assigned coach
* nutritionist same gym
* gym admin same gym

---

## GET /api/v1/nutrition/plans/{planId}

Return:

plan details

days list

each day includes:

* date

* goal
* notes
* meal suggestion count
