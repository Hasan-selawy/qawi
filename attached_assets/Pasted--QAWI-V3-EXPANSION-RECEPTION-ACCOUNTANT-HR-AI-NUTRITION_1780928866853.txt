# QAWI V3 EXPANSION — RECEPTION + ACCOUNTANT + HR + AI NUTRITION

Add the following major modules to Qawi (قوي) gym management platform.

CONTEXT:

Read CLAUDE.md and project documentation before making any changes.

Current Stack:

* Backend: Java 19 + Spring Boot 3.x
* Database: PostgreSQL
* Auth: JWT + AccessGuard RBAC
* Web: React + TypeScript + Tailwind + shadcn/ui
* Mobile: React Native + Expo
* Architecture: Multi-tenant SaaS
* Theme:

  * Background: #0A0F1E
  * Primary: #22C55E
  * Arabic-first
  * Full RTL support

IMPORTANT:

All new roles must use existing AccessGuard architecture.

All endpoints must enforce:

* gym isolation
* role permissions
* tenant safety

No cross-gym access is allowed.
