# QAWI — AI NUTRITION SYSTEM V2 — MYFITNESSPAL STYLE

## IMPORTANT

Read CLAUDE.md and project documentation before making changes.

Do NOT build Reception in this task.

Do NOT build HR in this task.

Do NOT rebuild the full app.

Do NOT delete old nutrition data.

Do NOT break existing workout, coach, member, sales, employees, or reception features.

This task is only for rebuilding Nutrition into a MyFitnessPal-style food logging system with AI macro calculation.

The old nutrition system is basic:

* Coach creates NutritionPlan
* Coach adds Meal entries

That is not enough.

New nutrition system should work like:

* Coach or Nutritionist sets daily targets
* Member logs what they ate
* App calculates calories, protein, carbs, fat
* Arabic food cache is checked first
* AI is used only when food is not found locally
* Food result is cached so the same food does not cost AI again

---

Current roles may include:

If NUTRITIONIST role already exists, reuse it.

# GOAL

Build a modern nutrition system similar to MyFitnessPal.

The member should be able to:

* Search food
* Log food
* Type Arabic or English food names
* Enter quantity and unit
* See calories and macros
* See daily progress toward targets
* Track water
* View history

Coach or Nutritionist should be able to:

* Set nutrition targets for a member
* View member food logs
* View adherence for last 7 days
* Add optional meal suggestions
* See whether member is hitting calories/protein

# NUTRITION WORKFLOW BY GYM

Some gyms have no nutritionist.

Some gyms have a nutrition department.

Support this with gym setting:

nutritionWorkflow enum:

* COACH_ONLY
* NUTRITIONIST_ONLY
* COACH_AND_NUTRITIONIST

If this field already exists from Employees task, reuse it.

If it does not exist, add it to Gym safely.

Default:

COACH_ONLY

Meaning:

## COACH_ONLY

Coach can set nutrition targets and view logs.

Nutritionist role may exist but is not required.

This fits small gyms.

## NUTRITIONIST_ONLY

Coach manages workouts only.

Nutritionist manages nutrition.

Coach can view nutrition summary but cannot edit targets.

## COACH_AND_NUTRITIONIST

Coach and nutritionist can both view nutrition.

Nutritionist has primary edit access.

Coach can add suggestions and view logs.

# SAFETY AND PRODUCT RULES

Nutrition values are estimates.

AI can be wrong.

Show small disclaimer:

"Nutrition values are estimates and may vary by preparation."

Do not generate medical diet advice.

Do not create extreme calorie targets automatically.

Targets are set by coach/nutritionist.

If targetCalories is below a safe minimum, show validation warning.

Use reasonable validation:

targetCalories must be between 1000 and 6000

targetProtein must be between 0 and 400g

targetCarbs must be between 0 and 800g

targetFat must be between 0 and 300g

targetWater must be between 0 and 10L

Do not block existing old data.

OPENAI_NUTRITION_MODEL

You are a nutrition calculator specializing in Middle Eastern and Arabic cuisine.
