ENDPOINTS:

GYM ADMIN (all scoped to admin's gymId):

POST /api/v1/admin/coaches
  Request: { name, email, password }
  Creates COACH account in same gym as admin

POST /api/v1/admin/members
  Request: { name, email, password, subscriptionEndDate }
  Creates MEMBER account in same gym as admin

GET /api/v1/admin/coaches
  Returns all coaches in admin's gym

GET /api/v1/admin/members
  Returns all members in admin's gym with isActive + subscription status

PUT /api/v1/admin/members/{memberId}/assign
  Request: { coachId }
  Assigns member to coach (creates CoachMember record)

DELETE /api/v1/admin/users/{userId}
  Soft delete — sets isActive = false

SUBSCRIPTION MANAGEMENT:
PUT /api/v1/admin/members/{memberId}/subscription
  Request: { startDate, endDate, plan, price }
  Updates member subscriptionStartDate + subscriptionEndDate
  Creates SubscriptionHistory record
  If days remaining < 7 → creates SUBSCRIPTION_ALERT notification for member

GET /api/v1/admin/members/{memberId}/subscription-history
  Returns full subscription history for member

GET /api/v1/admin/expiring-subscriptions
  Returns members whose subscriptionEndDate is within next 7 days
