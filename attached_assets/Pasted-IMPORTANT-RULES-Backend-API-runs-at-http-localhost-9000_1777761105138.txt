IMPORTANT RULES:
- Backend API runs at http://localhost:9000
- Store this in VITE_API_URL environment variable
- Do NOT modify the backend
- All API calls need Authorization: Bearer {token} header
- Roles are exactly: MEMBER, COACH, GYM_ADMIN, SUPER_ADMIN
- Login endpoint: POST /api/v1/auth/login
- After login route by role:
  GYM_ADMIN → /admin/dashboard
  COACH → /coach/dashboard
  SUPER_ADMIN → /super/dashboard

Build a production-ready React web dashboard for Qawi (قوي) gym management app.

TECH STACK:
- React 18 + TypeScript
- Vite
- React Router v6
- Axios
- Tailwind CSS
- Recharts
- TanStack Query (React Query)
- React Hook Form + Zod validation
- Framer Motion for animations
- date-fns for date formatting

CREATE WORKOUT PLAN PAGE (/coach/plans/create):
3-step wizard:
  Step 1: Plan name, member selection (dropdown), start + end date
           OR: "Use Template" button → template picker modal

  Step 2: Build schedule
    Calendar showing date range
    Click date to add a day
    For each day: day name EN + AR, toggle Training/Rest Day

  Step 3: Add exercises per day
    Category grid (Chest, Back, Legs, Shoulders, Arms, Core, Cardio with icons)
    Click category → exercise list
    Each exercise: Arabic name, default sets/reps/weight, video button
    Tap exercise → added instantly with default values
    Edit sets/reps/weight inline
    Custom exercise option

  Save → success animation → redirect to member detail
