PHASE 7A — Backend hardening.
DO NOT touch the frontend or mobile app.

1. INPUT VALIDATION:
Add @Valid to all controller endpoints.
Add Bean Validation annotations to all DTOs:
- @NotNull, @NotBlank on required fields
- @Email on email fields
- @Size(min=6) on passwords
- @Positive on price fields
- @Future or @FutureOrPresent on subscription dates
Return validation errors as:
{
  "error": "Validation failed",
  "fields": { "email": "must not be blank" },
  "timestamp": "..."
}

2. RATE LIMITING (Bucket4j):
Add to pom.xml: bucket4j-spring-boot-starter
Rate limits:
- POST /api/v1/auth/login → 5 requests per minute per IP
- POST /api/v1/public/register-gym → 3 per hour per IP
- All other endpoints → 100 per minute per user
Return 429 Too Many Requests with message:
{
  "error": "Too many requests. Please slow down.",
  "messageAr": "طلبات كثيرة جداً. يرجى الانتظار."
}

3. REQUEST LOGGING:
Add MDC logging to all requests:
- Log: method, path, userId, gymId, duration, status
- Format: [GET /api/v1/admin/members] userId=xxx gymId=xxx 
  duration=45ms status=200
- Use a filter/interceptor, not manual logging

4. HEALTH CHECK:
Add to pom.xml: spring-boot-starter-actuator
Expose: GET /actuator/health
Returns: { "status": "UP", "database": "UP" }
Secure it: only SUPER_ADMIN can access /actuator/**

5. PAGINATION:
Add Pageable to all list endpoints that return 
more than 20 items:
- GET /api/v1/exercises/library 
  → ?page=0&size=20&sort=name
- GET /api/v1/admin/members
  → ?page=0&size=20
- GET /api/v1/notifications
  → ?page=0&size=10
Return paginated response:
{
  "content": [...],
  "page": 0,
  "size": 20,
  "totalElements": 70,
  "totalPages": 4
}

6. EXCEPTION HANDLING:
Add global @ControllerAdvice to handle:
- NullPointerException → 500 with friendly message
- EntityNotFoundException → 404
- AccessDeniedException → 403
- MethodArgumentNotValidException → 400 with field errors
- DataIntegrityViolationException → 409 (duplicate email etc)
All errors must return Arabic + English message.
