ADD THESE ENTITIES:

ExerciseCategory:
  - id (UUID)
  - name (String)
  - nameAr (String)
  - iconUrl (String, nullable)

ExerciseTemplate:
  - id (UUID)
  - categoryId (UUID, FK → ExerciseCategory)
  - name (String)
  - nameAr (String)
  - defaultSets (int)
  - defaultReps (int)
  - defaultWeight (double)
  - videoUrl (String, nullable)
  - isCustom (boolean, default false)
  - createdByCoachId (UUID, nullable)

WorkoutTemplate:
  - id (UUID)
  - coachId (UUID, FK → User)
  - name (String)
  - nameAr (String)
  - description (String, nullable)
  - createdAt (LocalDateTime)

WorkoutTemplateDayEntity:
  - id (UUID)
  - templateId (UUID, FK → WorkoutTemplate)
  - dayNumber (int)
  - dayName (String)
  - dayNameAr (String)
  - isRestDay (boolean, default false)

WorkoutTemplateExercise:
  - id (UUID)
  - templateDayId (UUID, FK → WorkoutTemplateDayEntity)
  - exerciseTemplateId (UUID, nullable)
  - customName (String, nullable)
  - customNameAr (String, nullable)
  - sets (int)
  - reps (int)
  - targetWeight (double)
  - videoUrl (String, nullable)
  - orderIndex (int)

WorkoutPlan:
  - id (UUID)
  - name (String)
  - coachId (UUID, FK → User)
  - memberId (UUID, FK → User)
  - templateId (UUID, nullable FK → WorkoutTemplate)
  - startDate (LocalDate)
  - endDate (LocalDate)
  - createdAt (LocalDateTime)

ScheduleDay:
  - id (UUID)
  - workoutPlanId (UUID, FK → WorkoutPlan)
  - dayDate (LocalDate)
  - dayName (String)
  - dayNameAr (String)
  - isRestDay (boolean, default false)
  - isCompleted (boolean, default false)
  - completedAt (LocalDateTime, nullable)

PlanExercise:
  - id (UUID)
  - scheduleDayId (UUID, FK → ScheduleDay)
  - exerciseTemplateId (UUID, nullable)
  - customName (String, nullable)
  - customNameAr (String, nullable)
  - sets (int)
  - reps (int)
  - targetWeight (double)
  - videoUrl (String, nullable)
  - orderIndex (int)

WorkoutLog:
  - id (UUID)
  - memberId (UUID, FK → User)
  - planExerciseId (UUID, FK → PlanExercise)
  - actualSets (int)
  - actualReps (int)
  - actualWeight (double)
  - loggedAt (LocalDateTime)

REST ENDPOINTS:

EXERCISE LIBRARY:
GET /api/v1/exercises/categories
GET /api/v1/exercises/library
GET /api/v1/exercises/library/{categoryId}
POST /api/v1/exercises/library (Coach only — add custom exercise)

WORKOUT TEMPLATES:
POST /api/v1/templates (Coach only — save plan as template)
  Request: { name, nameAr, description, days: [{dayName, dayNameAr, isRestDay, exercises: [...]}] }

GET /api/v1/templates (Coach only — list own templates)

GET /api/v1/templates/{templateId} (Coach only — get template detail)

DELETE /api/v1/templates/{templateId} (Coach only)

POST /api/v1/workouts/from-template (Coach only — create plan from template)
  Request: { templateId, memberId, startDate }
  Logic: auto-generates schedule days from template days starting from startDate

WORKOUT PLANS:
POST /api/v1/workouts (Coach only)
  Request: { name, memberId, startDate, endDate }

GET /api/v1/workouts/member/{memberId}
GET /api/v1/workouts/{planId}

POST /api/v1/workouts/{planId}/days (Coach only)
  Request: { dayDate, dayName, dayNameAr, isRestDay }

POST /api/v1/workouts/days/{dayId}/exercises (Coach only)
  Request: { exerciseTemplateId?, customName?, customNameAr?, sets, reps, targetWeight, videoUrl? }

PUT /api/v1/workouts/days/{dayId}/complete (Member only)
  Marks day as complete, logs timestamp

POST /api/v1/workouts/logs (Member only)
  Request: { planExerciseId, actualSets, actualReps, actualWeight }

GET /api/v1/workouts/logs/member/{memberId}
