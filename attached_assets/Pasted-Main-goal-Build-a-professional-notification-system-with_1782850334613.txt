11. Automatic job behavior

Automatic jobs must be duplicate-safe.

Examples:

Do not send the same membership expiry reminder twice for the same user, same subscription, same reminder day.
Do not send inactive-member alert every time the job runs.
Do not send class reminder more than once for the same class booking.
Do not send expired alert repeatedly every day unless settings allow it.

Use metadata JSON or delivery log to track unique notification keys.

Example unique keys:

membership_expiry:{gymId}:{userId}:{subscriptionId}:7days
membership_expiry:{gymId}:{userId}:{subscriptionId}:1day
membership_expired:{gymId}:{userId}:{subscriptionId}
inactive_member:{gymId}:{userId}:{thresholdDays}:{date}
class_reminder:{gymId}:{bookingId}:{minutesBefore}
