# Qawi - قوي | Smart Gym Management

## Overview
Qawi is a multi-tenant SaaS gym management platform
built with Java Spring Boot 3, PostgreSQL, React, 
and React Native.

## Roles
- SUPER_ADMIN: manages all gyms on the platform
- GYM_ADMIN: manages their gym, members, subscriptions
- COACH: manages assigned members, creates workout plans
- MEMBER: tracks workouts, attendance, nutrition

## Tech Stack
- Backend: Java 17, Spring Boot 3, PostgreSQL, JWT
- Web: React 18, TypeScript, Vite, Tailwind CSS
- Mobile: React Native, Expo SDK 51

## Running Locally
1. Clone the repo
2. Copy .env.example to .env
3. Set DATABASE_URL, JWT_SECRET
4. Run: cd qawi-backend && mvn spring-boot:run
5. Run: cd qawi-web && npm run dev
6. Run: cd qawi-mobile && npx expo start

## Environment Variables
DATABASE_URL=jdbc:postgresql://localhost:5432/qawi
DB_USERNAME=postgres
DB_PASSWORD=yourpassword
JWT_SECRET=your-256-bit-secret-key
PORT=9000
